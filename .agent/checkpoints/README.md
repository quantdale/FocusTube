# Checkpoints

Create one Markdown file when a milestone gate passes, for example `M1-media-viability-2026-09-01.md`.

Include:

- commit SHA;
- gate;
- commands/workflow run IDs;
- simulator/device identity;
- screenshots/artifacts;
- live extractor sample IDs if used;
- known deferred Medium/Low debt;
- next waypoint.

Checkpoint files are durable evidence for fresh-agent recovery.
