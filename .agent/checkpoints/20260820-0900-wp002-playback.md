## What changed
- `App/Playback/PlayerCoordinator.swift`: `@MainActor @Observable` coordinator owning `AVPlayer` + `AVPlayerViewController`. Delegates stream selection to `MediaStreamFilter.selectOnlineStream` (never >1080p), KVO-maps `AVPlayerItem.status` / `AVPlayer.timeControlStatus` into the `PlaybackState` machine, surfaces typed `PlaybackError`, exposes `loadAndPlay(videoID:)` over a `MediaExtracting` seam, and supports pause/resume/stop. `FocusTubeCore` remains AVFoundation-free.
- `App/Playback/PlayerView.swift`: `UIViewControllerRepresentable` wrapper around `AVPlayerViewController` plus `PlayerView` overlay for loading/failed states with retry. View recreation never resets the player because the coordinator is created once and injected.
- `App/RootView.swift`: injected a single `PlayerCoordinator` and added a minimal M1 viability demo (Home list entry opens the native player for a representative long-form sample). Replaced by the real subscription Home feed later.
- `FocusTubeTests/PlayerCoordinatorTests.swift`: deterministic tests — selection delegation, `AVPlayerItem` creation for the selected stream, `PlaybackError` mapping, no-playable-stream typed failure, extraction-error typed failure (all via a local `FakeMediaExtractor`, no network).
- `FocusTubeTests/PlaybackStartSmoke.swift`: opt-in live playback smoke (`FOCUSTUBE_LIVE_SMOKE=1`) that resolves a long-form sample, plays it natively, and asserts the coordinator reaches ready/playing. Skipped by default.
