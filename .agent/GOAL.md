# Durable Goal

Deliver a dependable personal iOS application named FocusTube that lets the user deliberately find, watch, comment on, and download long-form YouTube videos while structurally excluding Shorts and short-form infinite-consumption mechanics.

Success is not measured by feature count. Success means the app is reproducibly buildable from a Windows-authored repository, autonomously testable on remote iOS Simulator infrastructure, resilient in its media/download state handling, and usable offline on the target physical iPhone.
